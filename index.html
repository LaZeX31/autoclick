Sur ordinateur : glisse ce bouton dans tes favoris

2. Créer le favori (Chrome Android)

  1. Mets cette page en favori (menu ⋮ puis ☆).
  2. Ouvre tes favoris, modifie-le : nom AC, et colle le code à la place de l'adresse.
  3. Ouvre ton jeu, tape AC dans la barre d'adresse et choisis le favori dans les suggestions.
  4. Glisse la cible rouge où tu veux, règle les ms, touche Démarrer.

Sur iPhone (Safari) : même principe avec un favori, à lancer depuis le menu des favoris.

Tester ici d'abord

Lance le favori sur cette page : la cible doit compter les clics.

Si le copier ne marche pas

Une page web ne peut cliquer que dans la page où le favori est lancé. Si le jeu est dans un cadre d'un autre site ou ignore les clics simulés, utilise une appli d'auto-clic Android (service d'accessibilité).
